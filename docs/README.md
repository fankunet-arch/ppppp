## 核心前提（不可动摇）

1. **POS 主库完全只读。** 不写入、不改表、不改配置、不装插件。所有交互仅 `SELECT`。
2. **POS 主机性能极度受限。** 任何查询都必须命中索引、限制步长、限定字段。
3. **网络单向。** 门店可访问外网，外网不可访问门店。

## 数据分析基线

本文档中所有"实测"结论，来源于以下三份主库导出：

| 文件 | 内容 | 规模 |
|---|---|---|
| `pdb/192_168_2_40 (1).sql` | 主库完整结构（无数据） | 190 张表 |

| `history_order_detail.sql` | 历史订单明细样本 | 100 行 |
| `order_detail.sql` | 菜单 + 活动订单明细样本 | 667 个菜品 |

**数据覆盖期：2024-01-22 ~ 2026-08-13，共 927 个营业日。**
